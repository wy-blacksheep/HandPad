# Third-party components and release scope

Project-owned code uses the root MIT license. The following components and external media retain separate terms. 

| Component | Treatment |
| --- | --- |
| Vuplex 3D WebView | Commercial; omitted. Install separately under a valid license. The bundled license prohibits distributing source outside the purchaser's organization. |
| Syncfusion PMML evaluator | Commercial; omitted. The bundled package description requires a license. Package version discrepancy needs confirmation. |
| Unity / Meta SDK packages | Restored through the preserved package manifest and lockfile; vendor terms apply. Package cache is not distributed. |
| UnityMainThreadDispatcher | Included required runtime code and original Apache 2.0 license in its asset directory; upstream attribution retained. |
| OneEuroFilter | Upstream MIT license verified and included at `docs/licenses/OneEuroFilterUnity-MIT.txt`; original author credits retained. [Upstream](https://github.com/DarioMazzanti/OneEuroFilterUnity). |
| TextMesh Pro / Liberation Sans | Retained shader, font, and material assets keep their upstream terms. The Liberation Sans OFL notice is included with the font assets. |
| HandPad PMML model | Team-authored model; project MIT license applies. |
| Web images and maps | External media retain their source licenses. See [Commons attribution](docs/COMMONS_ATTRIBUTION.md) and [URL inventory](docs/WEB_CONTENT_INVENTORY.md). |
| p5.js / jQuery | Loaded from external CDNs; upstream terms apply. |
| Original trash icons and placeholder SVG | Covered by the project MIT license. |
| Paper PDF and figures in `media/` | Supplied publication materials for Ying, Rahman, Hu, and Heo, HandPad, DOI 10.1145/3859332. The supplied manuscript specifies Creative Commons Attribution; the publication's license and any embedded third-party credits govern these materials. |
| `media/HandPad-demo.mp4` | Original author-supplied demonstration video. |

Project-owned web integration scripts, task text, and ProgressVisualizer are covered by the root MIT license. External media and third-party components are not relicensed by their inclusion in this repository.

References: [Vuplex commercial license](https://support.vuplex.com/articles/commercial-library-license/), [Syncfusion licensing](https://www.syncfusion.com/nuget/license), [UnityMainThreadDispatcher](https://github.com/PimDeWitte/UnityMainThreadDispatcher).
